# TgmStudio — обновления

Файлы автообновления TgmStudio. В каждом релизе лежат:

- `TgmStudio-single-nx-win-x64.zip` — раздаточный архив новой версии;
- `manifest.json` — версия, ссылка на архив, SHA-256, размер и заметки.

Программа при запуске сравнивает свою версию с манифестом последнего релиза
и, если вышла новая версия, предлагает обновление в один клик.
